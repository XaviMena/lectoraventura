# LectorAventura

Sitio de animación a la lectura para básica superior. Autor: Xavier Mena Paredes.

**Página web (esto es lo que se abre en clase):**  
https://XaviMena.github.io/lectoraventura/

El repositorio (`github.com/XaviMena/lectoraventura`) es el archivo del código. GitHub Pages publica el sitio a partir de ese archivo.

Cada vez que se sube un cambio a la rama `main`, el sitio se actualiza solo.
