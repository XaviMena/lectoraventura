# LectorAventura

Sitio de animación a la lectura para básica superior. Autor: Xavier Mena Paredes.

**Página web (esto es lo que se abre en clase):**  
https://XaviMena.github.io/lectoraventura/

El repositorio (`github.com/XaviMena/lectoraventura`) es el archivo del código. GitHub Pages sirve la **página web** desde la rama `gh-pages`.

Para actualizar el sitio después de cambiar cuentos o código, hay que volver a publicar esa rama (no basta con subir `main`).
